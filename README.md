## 先说结论

我在做 Minecraft 的模组和服务器插件。**目标是几十个，做成优质的那一批，全部免费开源。**

做这些不赚钱。我白天有活，写代码是晚上和周末。卡住我的不是热情，是**钱**：测试服务器要钱，跑多版本客户端要机器，少数 AI 功能调模型要账单。

所以这篇 README 就一件事：**如果你觉得这事值得，赞助我。**

## 我在做什么

不吹单个项目，说范围。这些都做，陆续放出来：

- **玩法模组** — 新机制、新交互、对原版玩法的补丁式改造
- **服务器插件** — 权限、经济、活动、运维、反作弊辅助
- **性能优化** — 掉帧、卡服、原版遗留的坑
- **兼容移植** — Fabric、NeoForge、Paper 之间来回搬，脏活我干
- **工具链** — 给服主和整合包作者用的效率工具
- **AI 相关** — NPC 对话、内容生成，用得着才上，不为贴标签硬塞

**几十个不是口号。** 现在手上有一批在写，写完一个放一个，不放半成品。

## The short version

I write Minecraft mods and server plugins. **The goal is dozens of them, good ones, all free and open source.**

This does not pay. I have a day job; I write at night and on weekends. What stops me is not motivation, it is **money** — test servers cost, running multi-version clients costs, and the few AI features come with API bills.

So this README asks one thing: **if you think this is worth it, sponsor me.**

## What I'm building

Not one project — a scope. All of these, released as they are finished:

- **Gameplay mods** — new mechanics, new interactions, patch-style reworks of vanilla
- **Server plugins** — permissions, economy, events, ops, anti-cheat helpers
- **Performance** — stutters, laggy servers, vanilla leftovers
- **Compatibility and ports** — Fabric, NeoForge, Paper. The dirty jobs are mine
- **Tooling** — efficiency tools for server owners and modpack authors
- **A bit of AI** — NPC dialogue, content generation. Used where it is needed, never bolted on for a label

**Dozens is not a slogan.** A batch is in progress. Finished ones ship; half-done ones do not.

## Why I need your support

Bluntly: free things are carried by people, and people cannot write on an empty stomach.

| What is missing | Why it cannot be skipped |
|---|---|
| Test servers | Plugins must run on a real server, real players, real concurrency |
| Multi-version clients | One mod has to be verified across MC versions and loaders. That needs machines |
| Model APIs | Testing the AI features burns tokens |
| Time | The most expensive part. Sponsorship means fewer side gigs, more mods |

I am not asking for pity. I am asking you to **help me finish the thing while it is still free**.
